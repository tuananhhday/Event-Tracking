    Đổi mitmdump / cổng proxy
    Endpoint bổ sung & nâng cao

    Proxy chỉ ghi request trong allowlist và không tự gợi ý endpoint. Chưa biết endpoint: dùng phương án 01 (tab Endpoint) để tìm rồi thêm vào đây. Regex cần tương thích JS và Python.

    Cửa sổ test dùng profile riêng và giữ đăng nhập cho lần sau. Website cần đăng nhập: đăng nhập trong cửa sổ test trước khi ghi bước.

  2. Không có file đặc tả? Cứ thu thập, rồi bấm Tạo rule trên event thật ở tab Event. Rule đã lưu được tự nạp lại lần sau.

    Nhập file thay toàn bộ case hiện có. Nhập được cả khi phiên đang chạy, nếu chưa ghi bước nào. Event đã bắt được sẽ được đối chiếu lại ngay.

  3. Đang ở chế độ thu thập tự do. 1. Bấm ⚑ Đặt mốc, thao tác trên website. 2. Ở tab Event trực tiếp, bấm Tạo rule trên event muốn kiểm. 3. Sau khi có case, quay lại đây để ghi bước và nhận PASS/FAIL.

    Chọn test case

    Case này chưa được duyệt: kết quả sẽ là REVIEW. Mở Xem / sửa rule để duyệt.

    Bấm trước khi thao tác. Rule tầng JS queue sẽ là REVIEW / LAYER_UNAVAILABLE vì proxy không thấy dataLayer.

    Request đã gắn vào bước0

    2. Chờ 1–2 giây để request tracking gửi xong.
    3. Quay lại đây bấm Hoàn tất bước.
