Có file hướng dẫn tracking?

Chọn Excel, chọn sheet R1511 hoặc sheet cần kiểm tra. Tên event và chi tiết mẫu được giữ nguyên để xem cạnh dữ liệu thực tế.

  1. 1Chọn fileXLSX hoặc JSON
  2. 2Chọn sheetXem đúng phiên bản
  3. 3Đối chiếuChi tiết từng trường
Đặc tả AppOTA và website có thể khác nhau thế nào?

Mẫu AppOTA dùng default_parameters/custom_parameters có thể khác payload website. Ứng dụng giữ nguyên bằng chứng và báo rõ phần chưa khớp. Payload mẫu không được tính là event đã thu thập.
