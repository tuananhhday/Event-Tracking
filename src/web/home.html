Đối chiếu theo file hướng dẫn

Trong chế độ đã chọn: chọn file XLSX → chọn sheet (ví dụ R1511) → Nhập file. Tab Đối chiếu đặc tả giữ nguyên Event Name, mô tả, chi tiết payload và vị trí dòng trong Excel. Bấm Xem chi tiết đặc tả để xem cả khi event chưa phát ra.

Mẫu AppOTA dùng default_parameters/custom_parameters có thể khác cấu trúc event website. Các trường không khớp sẽ được báo rõ; dữ liệu mẫu không phải event đã thu thập.
