# Tài liệu lịch sử

Các tài liệu ở đây ghi lại nghiên cứu ban đầu và kết quả triển khai tại thời điểm cũ. Không dùng số lượng test hoặc trạng thái tính năng trong đó để đánh giá bản hiện tại.

Hướng dẫn đang dùng: [README](../../README.md), [cấu trúc event](../EVENT_STRUCTURES.md) và [bản Windows](../../PORTABLE_WINDOWS.md).
